# Solo UTS GitHub Practicals

This directory contains practice implementations of Lectures 1-4.
Generated by `run_solo_practicals.py` for learning and inspection.

- Lecture 1: Git clone, branch, merge, amend, revert, reset and rebase conflict.
- Lecture 2: HTML/README automatic GitHub workflow.
- Lecture 3: Docker-based vowel analysis and custom action metadata.
- Lecture 4: Python task manager, unit tests, Docker CI and Project tracker.

Open the Git history and inspect the workflow runs to confirm results.
These scripts do not complete quizzes, write reflections, or create proof
that the user personally performed each activity.
